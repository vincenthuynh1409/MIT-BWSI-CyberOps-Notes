# July 27, 2026 (Zero Trust)

<u>Towards a Better Security Model:</u>
- Outdated:
	- Assumes that attackers can be kept out 
		- Cyber attacks like phishing bypass these defenses
	- Assumes insiders are never threats
	- Freedom of movement once inside
- ZERO TRUST Security Model:
	- Assumes attackers can get in
	- Assumes any insider can be a threat
	- Limits movement with mediated, fine-grained access control based upon identity and need-to-know (i.e. policy)

<u>Zero Trust Definitions:</u>
- **Zero Trust** = set of security principles that treats every component, service and user of a system as continuously exposed to and potentially compromised by malicious adversary
- **Zero Trust Architecture (ZTA)** = one that can support its intended mission while maintaining Confidentiality, Integrity, and Availability (CIA) requirements following Zero Trust security principles.

<u>Impact and Maintenance:</u>
- Reframed Focus:
	- From: "Patch everything!"
	- To: "Do not let the adversary get here!"
- Users:
	- Main users - no/minimal impact
	- Admin users - additional effort to use custom Privilege Escalation Tool to check out privileges to do work, but that should be harder to do and admin users understand 
- Verification:
	- At least 2 Penetration Testers per year since 2006
	- CISA 2021 Red Team Result - no access to unpatched vulnerability, no privilege escalation, no access to any system or data - brief stated security is outstanding
- System Maintenance:
	- 10-20 hours of admin time per week\
