# July 20, 2026 (HPC)

**High-Performance Computing (HPC)** = ability to process data and perform complex calculations at high speeds.

<u>Moore's Law:</u>
- Industry standard for computer engineers
- It is not a scientific law but an observation that compute capability should increase at a logarithmic scale over time
- observation used by semiconductor industry to set goals for future innovations in computer architecture
- these innovations have a trickle down effect from high end compute servers to personal computing devices.

<u>Processor Speed vs Density:</u>
- **CPU** = Central Processing Unit
	- brain of the computer, performing complex software calculations
	- each CPU consists of one or many CPU cores, that are each able to independently perform these operations
	- while the number of CPU cores has increased over time per CPU, the clock speed or the number of calculations each CPU core can perform each second has not.

<u>What is a supercomputer?:</u>
- A collection of computers that are connected together and act as one single machine 
- these computers need to be configured the same, with access to the same software and data 
- they are connected together using high speed interconnects to share data with each other
- they are managed by a scheduler to allocate resource amongst the cluster of machines
- **A small & mighty Pi Cluster:**
	- due to supercomputers being composed of multiple machines, they are often simply referred to supercomputing clusters or clusters for short
	- cluster can be composed of any type of computing machines, even Raspberry Pis

<u>Resources does a Supercomputer have?:</u>
- Each compute node provides a user with the following resources:
	- **CPU cores**
	- **Memory**
	- **GPU** 
	- **Time**
- Not all compute nodes need to be identical, but they all need to produce the same answer

<u>Modern Data Centers:</u>
- With the increased demand for AI tools, data center are being built at a much larger scale than ever before
- These larger data centers provide the power and cooling to support large scale compute clusters with large numbers of GPUs
- Companies are investing more in power infrastructure than compute infrastructure today as that is the largest bottleneck
