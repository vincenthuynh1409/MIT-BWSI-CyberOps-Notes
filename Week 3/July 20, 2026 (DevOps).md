# July 20, 2026 (DevOps)

<u>What is DevOps?:</u>
- **DevOps** = visualized of a code integration, deployment, testing, monitoring, and basically everything it takes to release a product
- Not just building the software, but also the process of releasing it

<u>Thanks to DevOps:</u>
1) Developers can provide resources to public cloud without depending on IT to provision infrastructure
2) Continuous integration and deployment (CI/CD) processes automatically set up testing, staging, and production environments in the cloud or on-premises
3) Infrastructure-as-Code (IaC) is widely used to deploy environments declaratively, using tools like Terraform

<u>DevSecOps:</u>
- **DevSecOps** helps bring down vulnerabilities, maximizes test coverage, and intensifies the automation of security frameworks
- **DevSecOp**s is software development approach that integrates security practices intro every stage of DevOps lifecycle

<u>What is Git?:</u>
- Git is NOT GitHub
- **Git** lets you manage changes made to files and directories in a project. It allows you to keep track of what you did, undo any changes, and collaborate with others
- **Git** = a tool that tracks changes to your code
- **GitHub** = a platform where you can share and collaborate on Git repos.

<u>Continuous Integration Continuous Deployment (CI/CD):</u>
- DevOps practice that automates testing, building, and deploying code changes, enabling faster and more reliable software releases 

<u>Pipelines:</u>
- **CI/CD pipeline** is automated DevOps workflow that streamlines the software delivery process. Imagine a flow-chart, or steps where you push your code .
- Pipelines are the automated features that testes it, runs checks, etc...
